# ТЕХНІЧНЕ ЗАВДАННЯ: Етап 6 — Компактна ергономіка Mini App, Додавання 3 популярних послуг та Актуалізація цін ринку Франківська

## 1. Загальна інформація та мета етапу
- **Мета:**
  1. **Компактна ергономіка інтерфейсу Mini App:** оптимізувати простір на екрані смартфона. Зменшити висоту карток послуг зі 130px до ~52px (формат List Tile), об'єднати шапку студії в один лаконічний рядок, зробити компактним блок вибору майстрів, виправити зайвий нуль у футері (`350 грн 0`).
  2. **Додавання 3 популярних послуг:**
     - Комплекс з обов'язковим укріпленням гелем/акригелем (900 грн, 105 хв);
     - Чоловічий гігієнічний манікюр (500 грн, 45 хв);
     - Зняття штучного матеріалу без манікюру (200 грн, 30 хв).
  3. **Актуалізація занижених цін (відповідність ринку Івано-Франківська):**
     - Базовий Однотон: з 550 ➔ **750 грн**;
     - Френч / Градієнт: з 650 ➔ **900 грн**;
     - Японський Еко-манікюр: з 450 ➔ **600 грн**;
     - Нарощування нігтів з нуля: з 900 ➔ **1 100 грн**;
     - Корекція нарощення: з 750 ➔ **800 грн**.
- **GitHub Repository:** `https://github.com/RissAR/nails_bot.git` (гілка `main`)
- **Стек:** React, Tailwind CSS, FastAPI, SQLAlchemy 2.0 (Async), SQLite.

---

## 2. Суворі правила безпеки (Strict Security & Scope Discipline)
1. **Zero Hardcoded Secrets (КРИТИЧНО):** `BOT_TOKEN` та інші конфіденційні дані зчитуються **виключно з локального `.env`**. Заборонено записувати токени у файли коду.
2. **Zero Scope Creep:** Модифікувати тільки фронтенд компоненти (Header, ServiceList, MasterList, Footer), оновлення прайсу та сідінгу в БД.
3. **Git Автоматизація:** Після завершення роботи виконати:
   `git add . && git commit -m "feat: compact UI ergonomics, add 3 popular services and update market prices" && git push origin main`.

### 3.2. Ергономіка інтерфейсу Mini App (`frontend/src/`)

#### 1. Шапка студії (`frontend/src/components/Header.tsx`):
- Замінити три окремі великі прямокутники на єдиний компактний статусно-інформаційний рядок:
  ```tsx
  <div class="flex items-center justify-between text-[11px] text-nude-muted mt-1 px-1">
    <span>📍 вул. Січових Стрільців</span>
    <span>•</span>
    <span>🕒 09:00–20:00</span>
    <span>•</span>
    <span class="text-nude-green font-medium">✨ 100% стерильно</span>
  </div>
  ```
- Прибрати або зробити мініатюрною кнопку "Adds".
- Загальна висота шапки має зменшитися мінімум на 50px.

#### 2. Компактний список послуг (`frontend/src/components/ServiceList.tsx`):
- Перетворити кожну картку на елегантний **List Tile** висотою ~52px (замість 130px):
  - Прибрати дублюючий бейдж категорії (`КОМПЛЕКСИ МАНІКЮРУ`).
  - Зменшити внутрішні відступи до `py-2.5 px-3`.
  - Верхній рядок:
    - Зліва: радіо-індикатор + назва послуги (`text-xs font-bold text-nude-text`).
    - Справа: тривалість та ціна в один рядок (`text-xs font-bold text-nude-text whitespace-nowrap`: `90 хв • 750 ₴`).
  - Нижній рядок (під назвою):
    - Короткий опис в один рядок (`text-[10px] text-nude-muted truncate max-w-[240px]`).
- Вибрана послуга виділяється тонкою витонченою рамкою `border-[#D4A373]` та легкою плашкою `bg-[#FAF6F0]`.
- Тепер на один екран мобільного поміщається **6–8 послуг** без потреби довгого скролу!

#### 3. Компактний вибір майстра (`frontend/src/components/MasterList.tsx`):
- Замість високих вертикальних блоків із довгими описами зробити компактну сітку у 2 колонки (`grid grid-cols-2 gap-2`):
  - Кожна картка: кругла іконка/аватар + Ім'я (`text-xs font-bold`) + Бейдж (`Top Master` / `Master`) + короткий підпис досвіду (`4 роки` / `2 роки`).
  - Висота картки майстра ~65px.

#### 4. Виправлення футера (`frontend/src/App.tsx`):
- Знайти місце рендеру суми у футері, де виводиться зайвий нуль (на скріншоті було `350 грн 0`).
- Форматувати коректно: `{finalPrice} ₴` (якщо є знижка: `{finalPrice} ₴ (-{discount}% = {discountedPrice} ₴)`).

## 4. Критерії приймання та валідація (Acceptance Criteria)
1. У базі даних та через `GET /api/services` доступно 12 послуг з актуальними цінами ринку Івано-Франківська (Базовий 750 грн, Френч 900 грн, Укріплення 900 грн, Нарощування 1 100 грн, Чоловічий 500 грн тощо).
2. На екрані смартфона список послуг виглядає компактно: поміщається 6+ послуг одночасно, картки акуратні (~52px висотою).
3. Шапка компактна, без зайвих високих прямокутників.
4. Картки майстрів витончені та не розтягують вертикаль екрана.
5. У футері відсутній баг `350 грн 0`.
6. `npm run build` у `frontend/` збирається без помилок (код 0).
7. Усі токени завантажуються виключно з `.env`.
8. Зміни закомічені та відправлені на GitHub:
   ```bash
   git add .
   git commit -m "feat: compact UI ergonomics, add 3 popular services and update market prices"
   git push origin main
   ```
